The setup code, for the first run (its second line):
  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "mudesk.fullname" . }} -- cat /var/www/mudesk/data/setup-code.php

{{- if .Values.ingress.enabled }}

Open https://{{ .Values.ingress.host }}
{{- else if eq .Values.service.type "ClusterIP" }}

To try it from this computer:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "mudesk.fullname" . }} 8443:{{ .Values.service.port }}
then open https://localhost:8443
{{- else }}

Open https://<the service's address>:{{ .Values.service.port }}
{{- end }}

The pod must reach the RDP port of the remote computers. Wake-on-LAN does not leave a pod's network.
